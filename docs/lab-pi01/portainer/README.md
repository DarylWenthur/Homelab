# Portainer

**Status:** ✅ Production  
**Version:** Latest  
**Last Updated:** 2026-08-05

---

## Purpose

Portainer provides a web-based interface for managing Docker resources.

## Features

- Container management
- Image management
- Network management
- Volume management
- Docker stack deployment

## Configuration Files

- compose.yaml

## Access

https://portainer.home.arpa

## Notes

Portainer is published through Nginx Proxy Manager and secured with the wildcard certificate.
