# Nginx Proxy Manager

## Purpose

Provides reverse proxy services for all internal web applications.

## Features

- Friendly hostnames
- HTTPS
- Reverse proxy
- Wildcard SSL certificate

## Proxy Hosts

- Homepage
- Portainer
- Pi-hole
- Uptime Kuma

## SSL

A private Root CA and wildcard certificate secure all hosted services.
