# Proxy Hosts

The following services are published through Nginx Proxy Manager.

| Service | Hostname | Forward Port |
|----------|----------|-------------:|
| Homepage | homepage.home.arpa | 3000 |
| Portainer | portainer.home.arpa | 9443 |
| Pi-hole | pihole.home.arpa | 8080 |
| Uptime Kuma | uptime.home.arpa | 3001 |

## Common Configuration

- Block Common Exploits: Enabled
- Websockets Support: Enabled
- Force SSL: Enabled
- HTTP/2: Enabled
- HSTS: Disabled
